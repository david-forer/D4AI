# davidjforer.com

Source for [davidjforer.com](https://davidjforer.com), the site for Forersight, an AI operations consultancy run by David J. Forer. It serves founder-led businesses in the US and publishes a blog on practical AI operations.

## What is in the site

- **Service pages** for the AI Readiness Audit and the work that follows it.
- **Blog** with long-form articles grouped into topic hubs and pillar pages.
- **Builds** at `/built`, a showcase of automations and tools, each with a plain-language write-up.
- **Research** pages, plus guides and checklists on the resources page.
- **Tools** such as the Founder Bottleneck Test and the AI Readiness Snapshot.

## Stack

- [Astro](https://astro.build) 4 with MDX content collections
- Tailwind CSS and the Inter variable font
- Node 20 and a small Express server (`server.js`) that serves the built site with gzip and security headers
- Sitemap generated by `@astrojs/sitemap`

## Project structure

```text
/
├── public/              Static assets
├── scripts/             Site checks and content tooling
├── src/
│   ├── components/      Astro components
│   ├── content/
│   │   ├── blog/        Blog posts (MDX)
│   │   ├── builds/      Build write-ups
│   │   ├── research/    Research pages
│   │   └── config.ts    Content schema
│   ├── layouts/         Page layouts
│   ├── lib/hubs.ts      Hub and pillar definitions
│   ├── pages/           Routes
│   └── styles/          Global styles
├── nginx/               Reverse proxy config
├── nixpacks.toml        Build settings
└── server.js            Production server
```

## Run it locally

You need Node 20 or newer.

```sh
npm install
npm run dev
```

The dev server runs at `http://localhost:4321`.

## Commands

| Command | What it does |
| :-- | :-- |
| `npm run dev` | Start the dev server |
| `npm run build` | Build the site into `./dist/` |
| `npm run preview` | Preview the build locally |
| `npm start` | Serve `./dist/` with the production server |
| `npm run check` | Run the site checks against the live site |
| `npm run nest` | Regenerate the VS Code file nesting for blog posts from their frontmatter |

## Content

Posts live in `src/content/blog/` and follow the schema in `src/content/config.ts`. Hubs and pillars are defined in `src/lib/hubs.ts`, so check that file before adding a post to a new topic.

## Deployment

The `main` branch deploys automatically. Pushing to it publishes the site.
