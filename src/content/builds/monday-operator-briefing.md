## What it does

Every Monday at 6:10am this skill reads the live signals across my business: approval queues, recent activity, calendar, and the health of my scheduled automations. It rewrites my current focus file with the week's priorities and saves a dated briefing I read with coffee.

## How it works

The skill is a written procedure Claude Code follows on a schedule. It knows where every signal lives, what a healthy state looks like, and how to rank what needs attention. The output is 1 file to read and 1 file that steers the rest of my tools for the week.
